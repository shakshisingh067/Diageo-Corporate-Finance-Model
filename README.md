# Diageo Corporate Finance Model

This project presents an advanced corporate finance Excel model prepared for a potential Diageo-related case project.

## Project focus
- Financial analysis
- Assumption-driven modeling
- Scenario and sensitivity analysis
- Corporate finance decision support

## What this model includes
- Key assumptions and input drivers
- Financial projections
- Analytical outputs for decision-making
- Structured Excel-based modeling approach

## Purpose
This project reflects my practical work in corporate finance and financial modeling as part of my academic and professional development in finance.
